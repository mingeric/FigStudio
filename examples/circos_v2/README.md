# Circos V2 example inputs

**Synthetic demonstration data only.** These rows are generated deterministically to exercise a 12-sector, 240-feature figure and are not biological observations or evidence. Replace all three CSV inputs with source-traceable study data before scientific use.

- `features.csv`: one record for every sector-local feature, including numeric score, direction, label, FDR, p-value, effect size, rank, and synthetic study identifier.
- `links.csv`: explicitly anchored shared-feature pairs.
- `sectors.csv`: display names and ordering.
